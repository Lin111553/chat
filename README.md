# 小聚：中文实时聊天

这是一个可运行的 Node.js 聊天应用，不再是只能在浏览器内自言自语的静态演示。包含账号注册/登录、SQLite 数据库、用户昵称搜索、私聊消息保存和 Socket.IO 实时收发。

## 本地启动

需要 Node.js 20 或更高版本。仓库根目录执行：

```bash
npm install
npm start
```

然后浏览器打开 `http://localhost:3000`。用一个昵称和至少 8 位密码注册，再在另一浏览器或无痕窗口注册另一个账号，就能搜索昵称并互相发送实时消息。

开发模式可运行 `npm run dev`。默认数据库为 `data/chat.sqlite`，首次启动自动创建。可通过 `DATA_DIR` 或 `DB_FILE` 指定数据库位置，通过 `PORT` 指定端口。

## 部署

需要支持持续运行 Node.js 服务和 WebSocket 的主机；GitHub Pages 只能托管静态文件，不能运行此服务器。将仓库部署到支持 Node.js 的应用主机，启动命令设为 `npm start`，并为 `data/` 配置持久化磁盘/卷。设置 `NODE_ENV=production` 并启用 HTTPS。若使用临时文件系统，重启或重新部署可能丢失 SQLite 数据。

## 安全与功能说明

- 密码使用 bcrypt 哈希保存；登录态使用随机 HttpOnly、SameSite=Lax Cookie，数据库只存会话令牌哈希。
- 页面与 API 同源提供，不启用跨域；登录和注册有速率限制。

- 新闻实时聚合尚未接入；页面会如实提示，不显示虚构的新华社、AP 或 BBC 新闻。
